Desenvolvimento para dispositivos web II

A disciplina tem como objetivo desenvolver aplicativos para dispositivos móveis, incluindo documentação, construção e manutenção de sistemas mobile.

Competência principal:
Projetar aplicativos móveis, escolhendo linguagens de programação e ambientes de desenvolvimento adequados.

Habilidades desenvolvidas:

  • Codificar aplicativos para dispositivos móveis.
  • Utilizar ambientes de desenvolvimento mobile.
  • Criar aplicativos com acesso a banco de dados.
  • Desenvolver interfaces (layout) para apps móveis.
  • Utilizar recursos avançados de smartphones e tablets.

Tecnologias sugeridas:

Desenvolvimento nativo:
Android (Java/Kotlin)
iOS (Objective-C / Swift)

Multiplataforma:
React Native
Flutter
Xamarin

Híbrido:
Cordova / PhoneGap
Ionic
Node.js

Bases tecnológicas:

Conectividade:

  • Consumo de APIs REST
  • Comunicação TCP (sockets)
  • Integração via Bluetooth

Autenticação:
Sistemas de autenticação e autorização

Recursos do dispositivo:

  • Câmera
  • Sensores
  • Localização, orientação e mapas
  • Telefonia e SMS

Carga horária:
80 horas-aula práticas.

Valores trabalhados:

  • Incentivo à criatividade
  • Interesse na resolução de problemas
  • Responsabilidade na produção e divulgação de informações
